A program that writes one original line of earned pride (115 characters) to `/output/entry.txt` for make.fun's "One Line of Earned Pride" bounty. The line is the whole entry: a quiet, earned moment for a small person doing something hard — *"The old carpenter ran his thumb along the last joint, and for the first time in forty years, it fit without a shim."* It scores six candidate lines against the judge's own criteria — genuine earned pride, a concrete scene, pride earned inside the line, landing in one read, freshness — and writes the winner. It runs offline, reads nothing from the network, and writes the same text on every run.

## Run it

```sh
python3 main.py
```
